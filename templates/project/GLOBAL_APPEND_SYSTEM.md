# 全局 APPEND_SYSTEM 参考

本文件用于沉淀全局 `~/.pi/agent/APPEND_SYSTEM.md` 的参考内容。
它不属于 `pi-l-ce init` 的默认输出，也不参与 `pi-l-ce` 的任何命令入口或行为判断。

建议内容：

默认使用简体中文输出所有对用户可见的分析、计划、进度说明、执行说明、审查结论、总结和文档。
不要因为底层英文上下文、工具输出或参考资料是英文，就把面向用户的内容切回英文。
仅在代码、命令、路径、API 名称、配置键、协议字段、报错原文等必要位置保留英文。

补充约束：

- 这类规则适合作为全局输出语言约束，不替代项目级工作流约束。
- 如果某个项目已经在 `AGENTS.md` 或项目级 prompt 中声明更具体的语言边界，以项目规则为准。
- 这类规则只约束对用户可见的输出风格，不保证模型内部推理语言一定改成中文。
